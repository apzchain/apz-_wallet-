# APZ WALLET  
کیف‌پول رسمی، سبک، امن و متن‌باز برای APZ Chain

APZ WALLET با هدف ایجاد یک تجربه‌ی شفاف، سریع و قابل‌بازتولید طراحی شده است.  
این کیف‌پول بدون وابستگی به سرویس‌های بسته، با معماری ماژولار و امنیت بالا ساخته شده است.

---

## ✨ قابلیت‌ها
- ایجاد کیف‌پول جدید (کلید خصوصی، کلید عمومی، آدرس APZ)
- امضای تراکنش‌ها با کلید خصوصی کاربر
- ارسال تراکنش خام به APZ RPC
- پشتیبانی از چند شبکه (Mainnet، Testnet، Devnet)
- نسخه موبایل اندروید با UI نئونی و انیمیشن
- نسخه وب سبک (HTML/CSS/JS)
- معماری ماژولار برای ادغام در پروژه‌های دیگر APZ
